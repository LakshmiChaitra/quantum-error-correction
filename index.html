01 / THE PRINCIPLE

Read parity.
Preserve information.

A repetition code spreads a logical basis state across an odd number of data qubits. The ZᵢZᵢ₊₁ checks detect disagreements without directly reading the logical bit. Two complementary error patterns share each syndrome; the decoder selects a correction.

02 / THE SCOPE

A focused model.
A transparent benchmark.

This reconstruction models independent bit flips with one perfect syndrome round. It does not simulate phase errors, noisy measurements or surface codes. The minimum-weight baseline is optimal here below 50% noise. The orbital artwork above is conceptual, not a simulation output.
